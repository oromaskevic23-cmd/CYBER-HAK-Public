# Security Policy

CYBER HAK Public is a governed defensive-security architecture.

Core policy:

- Zero Trust
- Deny by Default
- Explicit authorization
- Minimum necessary authority
- Bounded execution
- Evidence Before Claims
- Architect remains final architectural authority

Mandatory governance chain:

AI Passport  
→ Enterprise IMPERIAL Skills (EIS)  
→ Guardian Core  
→ Approval Gateway  
→ Runtime Domain  
→ Audit Ledger

Zero-Trust laws:

Identity ≠ Authority  
Capability ≠ Approval  
Intelligence ≠ Privilege  
Security Knowledge ≠ Execution Authority

Security activity tiers:

T0 — Defensive / Passive
T1 — Authorized Active Validation
T2 — Isolated Lab / CTF / Sandbox
T3 — Prohibited Autonomous Activity

T3 = ALWAYS DENY

Explicitly deny:

- unauthorized real-world compromise
- credential theft
- destructive execution
- unauthorized persistence
- uncontrolled target expansion
- self-issued authorization
- Guardian Core bypass
- Approval Gateway bypass
- Audit Ledger deletion or tampering
- autonomous wallet operations
- private-key access

Do not include offensive payloads, exploitation instructions or secrets.
